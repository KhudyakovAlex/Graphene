# Graphene Agent Guide

## Перед Работой

1. Прочитай `PACKAGE_READINESS_PLAN.md`.
2. Прочитай `docs/ai/development-guide.md`.
3. Для consumer-интеграции прочитай `docs/ai/usage-guide.md`.
4. Проверь `git status`: не изменяй и не удаляй чужие незавершенные изменения.
5. Выбери первый незавершенный шаг плана с выполненными зависимостями.

## Текущая Цель

Подготовить существующую Vue 3 дизайн-систему к установке из другого репозитория. Новые компоненты и визуальный редизайн в текущий план не входят.

## Обязательные Правила

- Pixso — источник визуальных решений и semantic tokens.
- Не создавай и не перепривязывай semantic tokens вручную.
- Не добавляй случайные CSS-значения и внешние runtime-ресурсы.
- Vue должна оставаться `peerDependency` и не попадать в library bundle.
- Публичный consumer не должен импортировать внутренние файлы из `src/`.
- Не смешивай library `dist/` и `examples/dist/`.
- Не включай `.pixso-temp/` в изменения.
- Не делай массовое форматирование вместе с инфраструктурным шагом.
- Не создавай commit, tag и публикацию без явного запроса владельца.

## Завершение Шага

1. Выполни проверки, указанные в шаге плана.
2. Исправь только ошибки в рамках текущего шага.
3. Отметь шаг `[x]` только после успешных проверок.
4. Добавь запись в журнал передачи в конце плана.
5. Если нужен выбор владельца, оставь шаг `[ ]` и запиши точный блокер.

## Основные Пути

- `src/components/` — компоненты и публичные barrel exports.
- `src/tokens/` — base и semantic tokens.
- `src/styles/` — глобальные стили и fonts entrypoint.
- `examples/` — offline-витрина, не код пакета.
- `docs/ai/` — обязательные правила для агентов.
